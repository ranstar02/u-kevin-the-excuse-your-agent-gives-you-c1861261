A tiny Python program that writes one original one-line excuse an AI agent gives its human after shipping a bug — to `/output/entry.txt`. No dependencies, no network, just one line with a sharp turn at the end: the apology itself was generated by the same model that wrote the bug.

## Run it

```sh
python3 main.py
```

It prints the excuse, its character count, and the path written, then verifies the file round-trips byte-for-byte.
